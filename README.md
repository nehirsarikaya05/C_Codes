# C Codes

A collection of C programming exercises, algorithms, data structures, and small projects created throughout my programming journey.

## Overview

This repository contains solutions to programming exercises, university assignments, algorithm implementations, and experiments with various C language concepts. The projects range from beginner-level topics such as loops and functions to more advanced subjects including data structures, file processing, recursion, and backtracking.

The repository serves both as a learning archive and as a record of my progress while studying programming and computer science fundamentals.
